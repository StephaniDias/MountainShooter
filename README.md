# 🏔️ Mountain Shooter
 
Jogo 2D de tiro desenvolvido em **Python** com a biblioteca **Pygame**.
 
> 🚧 Projeto em desenvolvimento. Por enquanto o jogo conta com a janela principal e o menu inicial.
 
## 📋 Sobre o projeto
 
Mountain Shooter é um projeto de estudo para praticar desenvolvimento de jogos com Pygame, organização de código em pacotes e programação orientada a objetos.
 
## ✨ Funcionalidades
 
- [x] Janela principal do jogo
- [x] Menu inicial com imagem de fundo e opções
- [ ] Fase jogável
- [ ] Jogador e inimigos
- [ ] Sistema de tiros e colisões
- [ ] Pontuação
## 🛠️ Tecnologias
 
- [Python 3.12](https://www.python.org/)
- [Pygame 2.6.1](https://www.pygame.org/)
## 📁 Estrutura do projeto
 
```
MountainShooter/

```
 
## 🚀 Como executar
 
### Pré-requisitos
 
- Python 3.12 (ou superior) instalado
- Git
### Passo a passo
 
1. **Clone o repositório**
```bash
   git clone https://github.com/StephaniDias/MountainShooter.git
   cd MountainShooter
```
 
2. **Crie e ative um ambiente virtual**
   Windows (PowerShell):
```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
```
 
   Linux / macOS:
 
```bash
   python3 -m venv venv
   source venv/bin/activate
```
 
3. **Instale as dependências**
```bash
   pip install -r requirements.txt
```
 
4. **Execute o jogo** (sempre a partir da raiz do projeto)
```bash
   python main.py
```
